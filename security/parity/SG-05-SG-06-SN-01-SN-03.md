## What app-core does today (SG-05, SN-01, SN-03 core part)

- app-core has no network code: a search of crates/ for sockets and HTTP clients finds only `std::net::Ipv6Addr` text parsing in url.rs, and `fea06_01_nothing_before_the_press` checks breach.rs; `Check` only builds requests and reads answers the caller hands it.
- Each request is `GET https://api.pwnedpasswords.com/range/<5 hex>` with `User-Agent` and `Add-Padding: true` only (06-02); one per distinct prefix (06-03); excluded, empty, recycled and reference passwords are not sent (06-14, 06-15); lines with count 0 (padding) are "not found" (06-05).
- Checker items re-run with its probe: an online count past the 64-bit range stops at the maximum; an entry excluded after the run leaves the findings; `answer` and `requests` use a prefix index (100,000 entries: `Check::new` 0.53 s, 85,252 answers 2.70 s, under fuzzing load).
- Memory: after `Check::new`, `requests`, an answer, `after_edit` and the offline check, freed memory holds no password, full hash or suffix, and no raw hash bytes of a file record (the 20-byte record buffer is wiped); the only hex hits are the probe's own copy of the file text.
