# SF-05 Header hash and header HMAC before decrypting

Row: SF-05 in [plan/security.md](../../plan/security.md). Stories: E3-S2, E3-S4.
Date: 2026-10-25 (Sprint 2). Status: verified (read side; App writes the hash and HMAC with E3-S7, FMT-05.9).

## What was proven

App checks the plain header hash, then the keyed header HMAC, before it reads or decrypts any payload byte. A wrong key is found at the HMAC and only there (version 4). Version 3 has no header HMAC; its wrong-key check is the start bytes (FMT-05.11, LD-12).
