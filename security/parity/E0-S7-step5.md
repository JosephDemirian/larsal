## 9. Item 3 skipped: rcgen

The net tests make their certificates in each run with rcgen, valid from last year to next year, because Apple's TLS verifier refuses a server certificate valid for more than 825 days; the test file says so ("made fresh by every run ... so no file can expire"). Fixed certificates would expire within about two years and break the tests, or would need a clock seam in Larsal's TLS verifier, product code, for a test-only crate. rcgen is a dev-dependency only, and plan/architecture.md plans it as a normal dependency of larsal-server (the first-start certificate), so it would come back. The tests would not stay as strong, so item 3 is not done.
