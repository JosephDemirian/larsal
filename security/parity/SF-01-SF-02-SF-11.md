## Interop matrix with the reference command line tool (installed 2.7.11)

A scratch Verify program opened `testdata/rich-v4.appvault` with App's reader, set the vault's encryption settings, and saved with `app_format::save`: 3 ciphers × 3 key derivations × compression on and off = 18 files. Settings: AES-KDF 200,000 rounds; Argon2d 2 iterations, 64 MiB, 2 lanes; Argon2id 3 iterations, 32 MiB, 4 lanes.

1. **App writes, the reference reads.** For each of the 18 files the reference's `db-info` named the cipher and KDF that were set. `scripts/testdata/interop_compare.py` then compared the reference's export of the file with its export of the original: equal in all 18 (10 entries, 3 history items, 55 fields with their protection flags, 5 of 5 attachments byte-equal). An independent header read (Python) showed fields 2, 3, 4, 7, 11, 0 only, compression flag 0 or 1 as set, Argon2 version 0x13 and a 32-byte salt or seed in every file.
2. **The reference writes, App reads.** The reference re-saved each of the 18 files (adding a group with `mkdir`), so it wrote every cipher, KDF and compression combination itself. App's reader opened all 18, and every entry, field, attachment name and history count matched the reference's own export of the file.

| | AES-KDF | Argon2d | Argon2id |
|---|---|---|---|
| AES-256, gzip on / off | both directions equal / equal | equal / equal | equal / equal |
| ChaCha20, gzip on / off | equal / equal | equal / equal | equal / equal |
| Twofish-256, gzip on / off | equal / equal | equal / equal | equal / equal |

The G4 run (`REF_CLI=<reference CLI> scripts/interop.sh`) adds 12 testdata vaults and 18 reference test vaults resaved by App, all AES-256 with AES-KDF or Argon2d: every export equal (see [SF-08](SF-08.md)).
