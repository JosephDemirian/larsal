## Side by side with the reference command line tool (installed 2.7.11)

300 passwords per option set from each tool (`generate` and App's command-line options), compared by the characters used, the lengths and, with `--every-group`, the groups present:

| Options | Result |
|---|---|
| none (lower, upper, digits; look-alike exclusion and every group on, as with neither flag) | same 53 characters, length 32 |
| `-L 64 -l` | same 25 characters |
| `-L 40 -U -n` | same 28 characters |
| `-L 40 -s` | same 31 characters |
| `-L 40 -lUns --exclude-similar` | same 84 characters |
| `-L 40 -ln -x aeiou0` | same 26 characters |
| `-L 30 -c abc123` | same 6 characters |
| `-L 40 -e` | 93 characters each; the reference drops U+00F9 as its "look-alike", App drops U+00B7 (D-02-1, on purpose) |
| `-L 8 -lUns --every-group` | the reference refuses (its special set is six groups, more than 8 characters can cover); App makes the password (one special group, D-02-2, on purpose) |

`diceware -W 3`, `7` and `12` against App's passphrases: same word counts, lower case, one space. App's words all come from the published EFF list (7,776 words, check value `6d557f06...c522` recomputed from the shipped file); the reference ships its own changed 7,772-word list (D-03-1, on purpose).
