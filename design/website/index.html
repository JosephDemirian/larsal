Security You Can Read

Everything is encrypted on your Mac before it is saved. Nobody else holds a key, not even the people who make App.

Your Password Stays With You

App stretches your vault password with Argon2id into a key that lives only in memory and is wiped the moment you lock.

Everything Is Sealed

Every entry, note and attachment is encrypted with AES-256 or ChaCha20 inside a single vault file.

Only Ciphertext Moves

Sync folders, backups and USB sticks only ever see encrypted bytes. Without your password and keys, the file is noise.
